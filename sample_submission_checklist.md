# Submission checklist

- [ ] App runs locally with `streamlit run app.py`
- [ ] Uploading a `.vtt` transcript works
- [ ] Local baseline returns a result
- [ ] If permitted, API mode works with a secret key stored outside source code
- [ ] Tested across labelled samples and errors documented
- [ ] Tested on an unseen recording
- [ ] Hosted app URL is accessible
- [ ] GitHub repo has README and source code only
- [ ] No confidential recordings/transcripts committed or publicly hosted
- [ ] AI interaction logs exported and redacted
- [ ] Approach note is no more than 300 words
